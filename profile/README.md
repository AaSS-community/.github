**AaSS (Agent as Software Solution) is a software ownership model where an AI agent builds, runs and maintains software you own, instead of software you rent.** More: [aass.co/what-is-aass](https://aass.co/what-is-aass)

## Start here

- **[SiteCrew AaSS Kit](https://github.com/AaSS-community/SiteCrew-AaSS-kit)**: a free kit (MIT) that puts your website on Cloudflare Pages, with an AI coding agent that builds it and keeps it. Nothing is published until you say "yes, publish". It put [aass.co](https://aass.co) live on Oct 2, 2026.
- **[aass.co](https://aass.co)**: what AaSS is, lessons, and stories, with a receipt for every number.
- **[AaSS.community](https://aass.community)**: the free community. Coming soon.
- **[The Practical AI Community](https://practicalai.community)**: the paid community, with the tested solutions. Coming soon.

The kit is an example, not a product: take it and build your own solution with it.
